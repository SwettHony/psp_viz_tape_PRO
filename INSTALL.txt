VIZ TAPE 1.2 — HOW TO INSTALL
An animated cassette for the PSP Music player (6.61 ARK-4)
Models enabled: PSP-1000, PSP-2000, PSP-3000, PSP Go and PSP Street/E1000.

WHAT YOU NEED
  - Your PSP with 6.61 ARK-4, and a USB cable (or a memory card reader).
  - This ZIP, unzipped. It contains a "seplugins" folder.

INSTALL
  1. Connect the PSP to your computer and turn on USB mode.

  2. Copy the "seplugins" folder from this ZIP onto the memory card
     or PSP Go internal storage, at the top level (next to the PSP folder).
     If a seplugins or SEPLUGINS folder already exists, merge the folders.
     When updating, replace viz_tape.prx with the new copy; keep other plugins.

  3. Open seplugins/PLUGINS.TXT on that storage device with a plain-text editor
     (TextEdit on a Mac: Format > Make Plain Text; Notepad on Windows).
     If there is no PLUGINS.TXT, create one. Add this one line at the end:

       vsh, ms0:/seplugins/viz_tape/viz_tape.prx, on

     For PSP Go internal storage, use this line INSTEAD:

       vsh, ef0:/seplugins/viz_tape/viz_tape.prx, on

     Keep one Viz Tape entry. Generated files stay in seplugins/viz_tape
     on the same storage device as the PRX.

     Keep other plugins' lines. When updating, replace the old Viz Tape
     entries with the one line above. Save it as PLUGINS.TXT.

  4. Eject the memory card on your computer, exit USB mode and restart the PSP.

  5. Play a song in the Music player and switch to the LAST visualizer.

  The first time the PSP starts with Viz Tape, it makes the little cassette
  icon for the visualizer menu during startup, ready for the first Music
  session. Nothing else to do.

UPDATING FROM AN OLDER VERSION
  Replace the two old Viz Tape lines in PLUGINS.TXT with the single line
  above. Copy the new seplugins folder over the old one, then restart the
  PSP before opening Music. Delete the old viz_tape_render.prx file; the
  renderer is now included inside viz_tape.prx.
  An enabled.txt from version 1.0 is no longer needed; you can delete it.

TURN OFF OR UNINSTALL
  Turn off:  change "on" to "off" on the Viz Tape line, then restart.
  Uninstall: delete that line and the seplugins/viz_tape folder, then restart
             before opening Music again.

IF THE PSP WON'T START PROPERLY
  Viz Tape skips itself for one start if the previous start crashed, so it
  cannot get stuck in a loop. If you still need to, hold START while turning
  the PSP on to start without any plugins, then turn Viz Tape off as above.
  ARK's guide: https://github.com/PSP-Archive/ARK-4/wiki/Recovery

IF THE CASSETTE DOESN'T SHOW UP
  Check that the single line is in PLUGINS.TXT exactly as above,
  and that seplugins/viz_tape has viz_tape.prx.
  The plugin writes notes to seplugins/viz_tape/status.txt.
  After a failed startup, the recovery boot preserves those notes and adds
  its skip reason. This build identifies itself as 1.2 and records
  the model ID, storage device and user-memory partition.
  A RENDERER load/start failure leaves the stock visualizer selected.

TESTING STATUS
